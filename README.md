### Часть 1. chapter1.bat

Ключевые участки кода:

- В начале обнуляются баллы кандидатов `score_yc`, `score_sel`, `score_tw`.
- Каждый вопрос задаётся через `choice`, ответ читается из `%errorlevel%` и сохраняется в переменную профиля проекта (`profile_scale`, `profile_budget`, `profile_time`, `profile_team`, `profile_services`).

- В конце выбирается платформа с максимальным числом баллов, результат записывается в `lab_rec` для главного файла.

### Часть 2. chapter2.bat

Ключевые участки кода:

- Счётчики `correct`, `total`, `score` задаются в начале файла.
- Для каждого фрагмента вызывается подпрограмма `:check`, которая принимает номер правильного ответа и пояснение.
- Верный ответ даёт +10 очков, неверный отнимает 5.
- Процент точности считается как `correct*100/total`, по нему определяется уровень Junior, Middle или Senior (переменная `lab_level`).

```bat
@echo off
chcp 65001 >nul
title Модуль 2 - Инспекция кода
cls

rem ============================================================
rem  Модуль 2. Формализация процесса ревьюирования кода
rem  Вариант 4: фрагменты кода для работы с облачной платформой
rem ============================================================

rem --- Начальные значения счётчиков ---
set /a correct=0
set /a total=5
set /a score=0
set "lab_level="

echo ============================================
echo   МОДУЛЬ 2. ИНСПЕКЦИЯ КОДА
echo ============================================
echo Вам будут показаны 5 фрагментов кода для облачного MVP.
echo В каждом спрятан один дефект. Выберите его тип.
echo Правильный ответ: +10 очков, неправильный: -5 очков.
echo.
echo Типы дефектов:
echo   1. Неинициализированная переменная
echo   2. Мёртвое присваивание
echo   3. Утечка ресурса
echo   4. Магическое число
echo   5. Отсутствие обработки ошибок
echo.
pause
echo.

rem ------------------------------------------------------------
rem  Фрагмент 1: загрузка резервной копии в облачное хранилище
rem  Правильный ответ: 3 (файл не закрывается)
rem ------------------------------------------------------------
echo ---------- Фрагмент 1 из 5 (резервные копии в S3) ----------
echo 10: def upload_backup(path):
echo 11:     client = boto3.client("s3", endpoint_url=ENDPOINT)
echo 12:     f = open(path, "rb")
echo 13:     client.put_object(Bucket="mvp-backups", Key=path, Body=f.read())
echo 14:     return True
echo.
echo Какой дефект здесь скрыт? (1-5)
call :check 3 "Файл открыт в строке 12, но нигде не закрывается. Нужен with open или f.close."
echo.

rem ------------------------------------------------------------
rem  Фрагмент 2: расчёт стоимости виртуальных машин
rem  Правильный ответ: 4 (числа 730 и 1.87 без имён)
rem ------------------------------------------------------------
echo ---------- Фрагмент 2 из 5 (расчёт стоимости) ----------
echo 20: def monthly_cost(vcpu_count):
echo 21:     return vcpu_count * 730 * 1.87
echo.
echo Какой дефект здесь скрыт? (1-5)
call :check 4 "Числа 730 часов в месяц и 1.87 руб. за час нужно вынести в именованные константы."
echo.

rem ------------------------------------------------------------
rem  Фрагмент 3: выбор региона размещения
rem  Правильный ответ: 1 (region не задан при is_eu = False)
rem ------------------------------------------------------------
echo ---------- Фрагмент 3 из 5 (выбор региона) ----------
echo 30: def pick_region(is_eu):
echo 31:     if is_eu:
echo 32:         region = "eu-central"
echo 33:     return region
echo.
echo Какой дефект здесь скрыт? (1-5)
call :check 1 "Если is_eu равно False, переменная region не создана, и return region вызовет ошибку."
echo.

rem ------------------------------------------------------------
rem  Фрагмент 4: создание виртуальной машины
rem  Правильный ответ: 2 (первое значение status сразу затирается)
rem ------------------------------------------------------------
echo ---------- Фрагмент 4 из 5 (создание ВМ) ----------
echo 40: def create_vm(name):
echo 41:     status = "pending"
echo 42:     status = api.create_instance(name)
echo 43:     return status
echo.
echo Какой дефект здесь скрыт? (1-5)
call :check 2 "Присваивание в строке 41 бесполезно: значение сразу перезаписывается в строке 42."
echo.

rem ------------------------------------------------------------
rem  Фрагмент 5: запрос статуса виртуальной машины
rem  Правильный ответ: 5 (нет try/except и проверки ответа)
rem ------------------------------------------------------------
echo ---------- Фрагмент 5 из 5 (статус ВМ) ----------
echo 50: def get_vm_status(vm_id):
echo 51:     response = requests.get(API_URL + "/vm/" + vm_id)
echo 52:     return response.json()["status"]
echo.
echo Какой дефект здесь скрыт? (1-5)
call :check 5 "Нет try/except и проверки кода ответа: при сбое сети или API программа упадёт."
echo.

rem ------------------------------------------------------------
rem  Итоговый отчёт
rem ------------------------------------------------------------
set /a percentage=correct*100/total

rem --- Уровень ревьюера: сначала Junior, затем повышаем по проценту точности ---
set "lab_level=Junior"
if %percentage% geq 50 set "lab_level=Middle"
if %percentage% geq 80 set "lab_level=Senior"

set lab_correct=%correct%
set lab_total=%total%
set lab_accuracy=%percentage%

echo ============================================
echo   ИТОГОВЫЙ ОТЧЁТ
echo ============================================
echo Просмотрено фрагментов: %total%
echo Правильных ответов: %correct%
echo Точность: %percentage%%%
echo Итоговые очки: %score%
echo Уровень ревьюера: %lab_level% Reviewer
echo.

pause
exit /b 0

rem ============================================================
rem  Подпрограмма :check
rem  %1 - номер правильного ответа, %2 - пояснение
rem  Ждёт нажатия клавиши 1-5, сравнивает с правильным ответом,
rem  меняет счётчик правильных ответов и очки.
rem ============================================================
:check
choice /c 12345 /n /m "Ваш ответ: "
set ans=%errorlevel%
if "%ans%"=="%~1" (
    echo Верно! %~2
    set /a correct+=1
    set /a score+=10
) else (
    echo Неверно. Правильный ответ: %~1. %~2
    set /a score-=5
)
exit /b
```

### Часть 3. chapter3.bat

Ключевые участки кода:

- Подпрограмма `:ask_num` принимает только целые числа из заданного диапазона и повторяет запрос при ошибке.
- Метка `:weights` возвращает к вводу весов, пока их сумма не станет равна 100.
- Баллы считаются по формуле `S = W1*X1 + W2*X2 + W3*X3 + W4*X4`.
- Матрица решений выводится в виде таблицы, победитель записывается в `lab_winner`. При равенстве баллов перечисляются все лидеры.

```bat
@echo off
chcp 65001 >nul
title Модуль 3 - Сравнительный анализ (WSM)
cls

rem ============================================================
rem  Модуль 3. Сравнительный анализ альтернатив методом взвешенной суммы
rem  Вариант 4: выбор облачной платформы для стартапа
rem  Альтернативы: Yandex Cloud (y), Selectel (s), Timeweb Cloud (t)
rem  Формула: S = сумма W x X, где W - вес критерия, X - оценка 1-5
rem ============================================================

set "lab_winner="

echo ============================================
echo   МОДУЛЬ 3. СРАВНИТЕЛЬНЫЙ АНАЛИЗ (WSM)
echo ============================================
echo Критерии:
echo   1. Стоимость владения
echo   2. Масштабируемость и автомасштабирование
echo   3. Управляемые сервисы (БД, Kubernetes, мониторинг)
echo   4. Простота освоения и скорость запуска MVP
echo.

rem ------------------------------------------------------------
rem  Ввод весов критериев. Сумма должна быть равна 100,
rem  иначе ввод повторяется.
rem ------------------------------------------------------------
:weights
echo Назначьте веса критериям, сумма должна быть равна 100.
call :ask_num w1 "Вес критерия 1 (Стоимость владения): " 0 100
call :ask_num w2 "Вес критерия 2 (Масштабируемость): " 0 100
call :ask_num w3 "Вес критерия 3 (Управляемые сервисы): " 0 100
call :ask_num w4 "Вес критерия 4 (Простота освоения): " 0 100
set /a total_weight=w1+w2+w3+w4
if %total_weight% neq 100 (
    echo.
    echo Ошибка: сумма весов равна %total_weight%, а должна быть 100. Повторите ввод.
    echo.
    goto :weights
)
echo.

rem ------------------------------------------------------------
rem  Оценки альтернатив по шкале 1-5 (5 - лучшее значение).
rem  Для стоимости 5 означает самую низкую цену.
rem ------------------------------------------------------------
echo Оцените альтернативы по шкале от 1 до 5 (5 - лучшее значение).
echo.
echo --- Yandex Cloud ---
call :ask_num y1 "Yandex Cloud по критерию 1 (Стоимость): " 1 5
call :ask_num y2 "Yandex Cloud по критерию 2 (Масштабируемость): " 1 5
call :ask_num y3 "Yandex Cloud по критерию 3 (Сервисы): " 1 5
call :ask_num y4 "Yandex Cloud по критерию 4 (Простота): " 1 5
echo.
echo --- Selectel ---
call :ask_num s1 "Selectel по критерию 1 (Стоимость): " 1 5
call :ask_num s2 "Selectel по критерию 2 (Масштабируемость): " 1 5
call :ask_num s3 "Selectel по критерию 3 (Сервисы): " 1 5
call :ask_num s4 "Selectel по критерию 4 (Простота): " 1 5
echo.
echo --- Timeweb Cloud ---
call :ask_num t1 "Timeweb Cloud по критерию 1 (Стоимость): " 1 5
call :ask_num t2 "Timeweb Cloud по критерию 2 (Масштабируемость): " 1 5
call :ask_num t3 "Timeweb Cloud по критерию 3 (Сервисы): " 1 5
call :ask_num t4 "Timeweb Cloud по критерию 4 (Простота): " 1 5
echo.

rem ------------------------------------------------------------
rem  Расчёт взвешенных баллов S = W1*X1 + W2*X2 + W3*X3 + W4*X4
rem ------------------------------------------------------------
set /a score_y=y1*w1+y2*w2+y3*w3+y4*w4
set /a score_s=s1*w1+s2*w2+s3*w3+s4*w4
set /a score_t=t1*w1+t2*w2+t3*w3+t4*w4

rem --- Выравнивание чисел по ширине для красивой таблицы ---
set "pw1=   %w1%"
set "pw2=   %w2%"
set "pw3=   %w3%"
set "pw4=   %w4%"
set "pty=     %score_y%"
set "pts=     %score_s%"
set "ptt=     %score_t%"

echo ================= Матрица решений =================
echo Критерий                              ^| Вес ^| Yandex ^| Selectel ^| Timeweb
echo ----------------------------------------------------------------------------
echo Стоимость владения                    ^| %pw1:~-3% ^|   %y1%    ^|    %s1%     ^|   %t1%
echo Масштабируемость                      ^| %pw2:~-3% ^|   %y2%    ^|    %s2%     ^|   %t2%
echo Управляемые сервисы                   ^| %pw3:~-3% ^|   %y3%    ^|    %s3%     ^|   %t3%
echo Простота освоения                     ^| %pw4:~-3% ^|   %y4%    ^|    %s4%     ^|   %t4%
echo ----------------------------------------------------------------------------
echo ИТОГО S = сумма W x X                 ^|     ^| %pty:~-5% ^| %pts:~-5%    ^| %ptt:~-5%
echo ============================================================================
echo (максимально возможный балл: 500)
echo.

rem ------------------------------------------------------------
rem  Определяем победителя. Если баллы равны, перечисляем всех лидеров.
rem ------------------------------------------------------------
set /a best=score_y
if %score_s% gtr %best% set /a best=score_s
if %score_t% gtr %best% set /a best=score_t

if %score_y% equ %best% call :add_winner "Yandex Cloud"
if %score_s% equ %best% call :add_winner "Selectel"
if %score_t% equ %best% call :add_winner "Timeweb Cloud"

echo Победитель: %lab_winner%
echo.

pause
exit /b 0

rem ============================================================
rem  Подпрограмма :ask_num
rem  %1 - имя переменной, %2 - приглашение, %3 - минимум, %4 - максимум
rem  Повторяет запрос, пока не введено целое число из диапазона.
rem ============================================================
:ask_num
set "val="
set /p "val=%~2"
if not defined val goto :ask_num_bad
set "chk="
for /f "delims=0123456789" %%a in ("%val%") do set "chk=1"
if defined chk goto :ask_num_bad
if %val% lss %~3 goto :ask_num_bad
if %val% gtr %~4 goto :ask_num_bad
set "%~1=%val%"
exit /b

:ask_num_bad
echo Ошибка: введите целое число от %~3 до %~4.
goto :ask_num

rem ============================================================
rem  Подпрограмма :add_winner
rem  Добавляет название платформы к строке победителей lab_winner.
rem ============================================================
:add_winner
if defined lab_winner goto :add_winner_more
set "lab_winner=%~1"
exit /b

:add_winner_more
set "lab_winner=%lab_winner% и %~1"
exit /b
```

Ключевые участки кода:

- Главное меню на метке `:menu` и переходы `goto` на нужный модуль.
- Модули запускаются через `call "%~dp0chapterN.bat"`, поэтому работают из любой папки и передают результаты через переменные.
- Пункт 4 запускает три модуля подряд, выводит итоговый отчёт и сохраняет его в `report.txt` в той же папке.

```bat
@echo off
chcp 65001 >nul
title Система моделирования процессов разработки ПО

rem ============================================================
rem  Главный файл: объединяет модули chapter1.bat, chapter2.bat, chapter3.bat
rem  Модули запускаются командой call в том же окне, поэтому их результаты
rem  (переменные lab_rec, lab_level, lab_winner) доступны главному файлу.
rem ============================================================

rem --- Значения по умолчанию, пока модули не пройдены ---
set "lab_rec=не определена"
set "lab_level=не определён"
set "lab_winner=не определён"

:menu
cls
echo ========================================
echo   СИСТЕМА МОДЕЛИРОВАНИЯ ПРОЦЕССОВ РАЗРАБОТКИ ПО
echo   Вариант 4: выбор облачной платформы для стартапа
echo ========================================
echo.
echo 1. Модуль выбора технологий
echo 2. Модуль инспекции кода
echo 3. Модуль сравнительного анализа
echo 4. Запустить все модули последовательно
echo 5. Выход
echo.
set "menu_choice="
set /p "menu_choice=Ваш выбор: "

if "%menu_choice%"=="1" goto :run1
if "%menu_choice%"=="2" goto :run2
if "%menu_choice%"=="3" goto :run3
if "%menu_choice%"=="4" goto :run_all
if "%menu_choice%"=="5" goto :quit

echo.
echo Неверный выбор. Введите число от 1 до 5.
pause
goto :menu

:run1
call "%~dp0chapter1.bat"
goto :menu

:run2
call "%~dp0chapter2.bat"
goto :menu

:run3
call "%~dp0chapter3.bat"
goto :menu

rem ------------------------------------------------------------
rem  Пункт 4: все модули подряд, затем итоговый отчёт и report.txt
rem ------------------------------------------------------------
:run_all
set "lab_rec=не определена"
set "lab_level=не определён"
set "lab_winner=не определён"
call "%~dp0chapter1.bat"
call "%~dp0chapter2.bat"
call "%~dp0chapter3.bat"

rem --- Сравниваем результаты модуля 1 и модуля 3 ---
set "lab_note=Результаты модулей 1 и 3 расходятся - стоит обсудить выбор в команде."
if "%lab_rec%"=="%lab_winner%" set "lab_note=Результаты модулей 1 и 3 совпадают - выбор платформы подтверждён."

cls
echo ========================================
echo   ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ
echo ========================================
echo Все модули пройдены.
echo.
echo Модуль 1: рекомендация по технологии - %lab_rec%
echo Модуль 2: уровень ревьюера - %lab_level% Reviewer, верных ответов %lab_correct% из %lab_total%, точность %lab_accuracy%%%
echo Модуль 3: победитель сравнительного анализа - %lab_winner%
echo.
echo %lab_note%
echo.

rem --- Сохраняем отчёт в report.txt в той же папке ---
(
    echo ========================================
    echo   ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ
    echo   Вариант 4: выбор облачной платформы для стартапа
    echo ========================================
    echo Дата и время: %date% %time%
    echo.
    echo Модуль 1. Рекомендация по технологии: %lab_rec%
    echo Модуль 2. Уровень ревьюера: %lab_level% Reviewer
    echo           Правильных ответов: %lab_correct% из %lab_total%, точность %lab_accuracy%%%
    echo Модуль 3. Победитель сравнительного анализа: %lab_winner%
    echo.
    echo %lab_note%
) > "%~dp0report.txt"

echo Результаты сохранены в report.txt
echo.
pause
goto :menu

:quit
exit /b 0
```

## Описание работы интегрированной системы

### Диалоги и вопросы

1. **Модуль 1.** Пять вопросов о проекте: масштаб нагрузки, бюджет в месяц, сроки запуска MVP, квалификация команды, потребность в управляемых сервисах. На каждый вопрос три варианта ответа.
2. **Модуль 2.** Пять фрагментов кода на Python, связанных с облаком (загрузка в S3, расчёт стоимости, выбор региона, создание ВМ, запрос статуса). В каждом нужно найти один из пяти типов дефектов.
3. **Модуль 3.** Ввод весов четырёх критериев (сумма 100), затем 12 оценок от 1 до 5 для трёх платформ.

### Рекомендации, полученные при запуске

- Модуль 1 рекомендовал: _впишите результат_
- Модуль 2: _впишите число верных ответов, точность и уровень_
- Модуль 3 определил победителя: _впишите результат_

### Впечатления от работы

Если честно, сначала я не думал, что на .bat-файлах можно сделать что-то похожее на настоящую программу. Раньше я с ними почти не работал. Но оказалось, что с командами `choice`, `set /a` и `if` можно сделать и вопросы, и подсчёт баллов, и даже таблицу.

Самым сложным было то, что в .bat-файлах много мелких ловушек. Например, скобки в тексте команды `echo` внутри блока `if` ломают весь блок. Ещё надо было разобраться, как работает `errorlevel` после `choice`, и как передать результат из одного модуля в другой. В итоге оказалось, что при вызове через `call` переменные просто остаются общими, и это сильно упростило интеграцию. Ещё пришлось повозиться с русскими буквами: без `chcp 65001` в консоли показывались непонятные символы.

Больше всего мне понравился третий модуль. Там сразу видно, как метод взвешенной суммы помогает выбрать вариант не «на глаз», а по цифрам. Когда меняешь веса, победитель может поменяться, и это наглядно показывает, что результат зависит от того, что для тебя важнее. А во втором модуле было интересно искать ошибки в чужом коде: я заметил, что неинициализированную переменную и мёртвое присваивание найти сложнее всего.

В целом лабораторная получилась полезной. Я понял, как из трёх маленьких частей собрать одну систему, и увидел, что даже выбор облака для стартапа можно описать понятными правилами. Но если бы такую систему делать всерьёз, лучше было бы писать её на Python, а не на .bat: кода было бы меньше и ошибок тоже.

## Инструкция по запуску

1. Скачайте репозиторий (кнопка **Code** -> **Download ZIP**) и распакуйте архив.
2. Убедитесь, что файлы `chapter1.bat`, `chapter2.bat`, `chapter3.bat` и `lab_system.bat` лежат в одной папке.
3. Запустите `lab_system.bat` двойным щелчком (Windows 10 или 11).
4. В меню выберите нужный пункт: 1-3 запускают отдельные модули, 4 проходит все модули подряд и создаёт `report.txt`, 5 завершает работу.
5. Каждый модуль можно запустить и отдельно двойным щелчком по его `.bat`-файлу.

Если вместо русских букв отображаются «кракозябры», откройте файлы в Notepad++ или VS Code, сохраните в кодировке OEM 866 и замените в начале каждого файла `chcp 65001` на `chcp 866`.
